🚀 UTILISATION RAPIDE

1. Cloner repo
2. python -m venv venv && source venv/bin/activate
3. pip install -r requirements.txt
4. cp .env.example .env (éditer avec vos paramètres MySQL)
5. python generate_data.py (générer données)
6. python load_data.py (charger en MySQL)
7. python rfm_pipeline.py (calculer segments)
8. python dashboard.py (lancer http://localhost:8050)
